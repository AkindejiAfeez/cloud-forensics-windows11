# Limitations and Future Work

## 1. Controlled Environment

The investigation was performed in a controlled virtual-machine environment.

This provides experimental control but does not fully represent the complexity of enterprise or real-world forensic investigations.

---

## 2. Single-User Environment

The experiments were conducted using a controlled user environment.

Further research should investigate multi-user and enterprise Windows environments.

---

## 3. Cloud Platforms

The investigation focused on:

- Microsoft OneDrive
- Google Drive

Other cloud-storage platforms were outside the scope of the project.

Future research could examine additional platforms and compare their forensic artefacts.

---

## 4. Memory Acquisition

One memory-acquisition attempt was affected by an interruption within the virtual-machine environment.

Although memory analysis produced useful findings in the relevant scenario, the limitation demonstrates the practical challenges associated with volatile evidence acquisition.

---

## 5. Full-Disk Imaging

A complete forensic disk image could not be produced for every scenario.

Future experiments should incorporate full-disk forensic imaging to provide a more comprehensive evidence source.

---

## 6. External Validation

The framework was developed and evaluated within the academic project environment.

External practitioner validation was not completed.

Future work should involve experienced digital-forensics practitioners reviewing and testing the framework.

---

## 7. Operating-System and Application Versions

Cloud-client behaviour can change between application versions and operating-system releases.

Consequently, the findings should be interpreted in the context of the Windows 11 and application configurations used during the experiments.

---

## 8. Future Research

Future work could extend the project through:

- Additional cloud-storage platforms
- Physical Windows endpoints
- Enterprise environments
- Mobile-device analysis
- Full-disk forensic imaging
- Additional encryption technologies
- Larger experimental datasets
- Practitioner validation
- Automated artefact extraction
- Automated timeline generation

These extensions could further evaluate the generalisability of the framework.
